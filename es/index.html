Datos sintéticos para la comunicación visual

2.000 diseños sintéticos con su imagen, 1.000 participantes ficticios y 20.000 respuestas simuladas, con todos los efectos generadores documentados. Para enseñar y probar análisis frente a una verdad conocida, sin riesgos de privacidad.

Descargar los datos Explorar los diseños GitHub

Todos los datos son sintéticos. Se generaron con un modelo estadístico documentado y semillas fijas. No representan a personas reales, diseños reales ni resultados empíricos, y no deben citarse como evidencia sobre la percepción humana.

Diez de las 2.000 imágenes sintéticas. El texto es pseudotexto sin significado y los rostros son esquemáticos; cada propiedad está registrada en las tablas.

Qué contiene

Un estudio simulado en el que personas observan diseños visuales y responden a ellos: tres tablas enlazadas, una imagen por diseño y los metadatos para interpretarlas.

Verdad conocida

Todos los efectos usados para simular las respuestas están en true_effects.csv, para comprobar si un modelo los recupera.

Imágenes coherentes con los datos

Cada imagen se dibuja a partir de su fila: el color del texto se calcula para lograr el contraste WCAG exacto, y la paleta, la tipografía, la maquetación y los gráficos siguen las variables.

Reproducible

Scripts en R base regeneran cada fichero byte a byte con semillas fijas, y 55 comprobaciones verifican sumas, claves, rangos y efectos.

Explora los diseños

Filtra los 2.000 diseños sintéticos y abre cualquiera para ver su imagen, sus variables, los colores dibujados y la media de las respuestas simuladas. Los nombres de las variables están en inglés, como en los ficheros.

R

base <- "https://pablosancheznunez.com/synthviscom/data/"
designs <- read.csv(paste0(base, "synthetic_designs.csv"), na.strings = "")
participants <- read.csv(paste0(base, "synthetic_participants.csv"))
responses <- read.csv(paste0(base, "synthetic_responses.csv"))
study <- merge(merge(responses, designs), participants)

Python

import pandas as pd
base = "https://pablosancheznunez.com/synthviscom/data/"
designs = pd.read_csv(base + "synthetic_designs.csv")
participants = pd.read_csv(base + "synthetic_participants.csv")
responses = pd.read_csv(base + "synthetic_responses.csv")
study = (responses.merge(designs, on="design_id")
                  .merge(participants, on="participant_id"))

Para docencia e investigación

El repositorio incluye un script de introducción y un cuaderno con nueve ejercicios resueltos (en inglés) para asignaturas de comunicación visual, diseño de información, visualización de datos, accesibilidad y métodos de investigación.

Auditoría de accesibilidad

¿Qué diseños no cumplen el contraste WCAG y a quién excluyen? La comprensión cae por debajo de 4,5:1, más en participantes con daltonismo o baja visión.

Modelos con respuesta conocida

Ajusta regresiones y modelos ordinales o mixtos y compáralos con los efectos reales; detecta sesgo por variable omitida y mediación.

Potencia por simulación

El generador crea estudios sintéticos nuevos de cualquier tamaño para ver cuántos participantes necesitaría un estudio real.

Crítica de diseño

Compara las imágenes de los diseños mejor y peor comprendidos y explica la diferencia con los datos.

Elección de gráficos

Representa el efecto del contraste en escala logarítmica, compara tipos de gráfico y ratios datos-tinta.

Análisis de imagen

Estima el contraste, el colorido o la densidad de texto a partir de los píxeles y compáralos con los valores registrados.
